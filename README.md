## 📌 Project Overview

**UrbanCart** is a modern e-commerce platform developed as a Graduation Project at Route Academy.
The application is built using React.js and focuses on delivering a smooth, responsive, and user-friendly shopping experience.

It includes secure authentication and protected routes, dynamic product sliders, and efficient data handling using React Query for caching and performance optimization.
The project also supports offline detection, robust form validation using Formik & Yup, and role-based access control using JWT.

## ⚙️ Tech Stack

* React.js
* HTML5 & CSS3
* Bootstrap
* Axios
* React Query
* Formik & Yup
* JWT Authentication
* Font Awesome

## ✨ Key Features

* User authentication & protected routes
* Product browsing with dynamic sliders
* Offline detection handling
* Data caching & performance optimization
* Form validation with Formik & Yup
* Role-based access control (JWT)
